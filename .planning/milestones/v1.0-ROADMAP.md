# Milestone v1.0: Foundation Framework

**Status:** ✅ SHIPPED 2026-05-30
**Phases:** 1–11
**Total Plans:** 13

## Overview

Data-driven Selenium workflow automation framework (Python 3.9.13) that reads workflow definitions from JSON and executes browser interactions across a hierarchy of Workflow → Tabs → Pages → Sections → Elements. v1.0 established the complete feature set for zero-Python-per-workflow authoring, from the foundational `$ref` loader through conditional workflow composition.

## Phases

### Phase 1: Support Nested JSON

**Goal**: Enable `$ref` file references in workflow JSON so shared tabs/pages/sections can be reused across workflows
**Depends on**: Nothing (first phase)
**Plans**: 2 plans

Plans:
- [x] 01-01: Implement `resolve_refs` and wire into `WorkflowLoader`
- [x] 01-02: Refactor sample workflows to use `$ref` file references

**Details:** Recursive `resolve_refs(data, base_dir)` with `frozenset`-based circular reference guard. Full-replacement `$ref` semantics (no sibling key merging). Existing smoke tests validated against `$ref`-based sample workflows.

**Details:** `ParameterDefinition` Pydantic model + `parameters: Optional[List[ParameterDefinition]]` on `WorkflowDefinition`. ## Milestone Summary

**Key Decisions:**

- Phase 1: `resolve_refs` uses `frozenset`-based circular ref guard; `$ref` is full-replacement (no sibling merging)
- Phase 4: Anchored regex `^\$\{([^}]+)\}$` — full-value-only matching, no partial expansion
- Phase 5: Reused `WaitConditionDefinition.timeout` for sleep duration — no schema change needed
- Phase 6: Value-only JS execution (`driver.execute_script(str(value))`) — no element binding
- Phase 10: `env:` namespace prefix routes to `_ENV_CONFIG` before `PLACEHOLDER_REGISTRY`
- Phase 11: None-sentinel pattern for list filtering; `params: dict | None = None` to avoid mutable default

**Known Deferred Items:**

- Phase 3: 2 browser-level UAT scenarios pending live ChromeDriver execution (new window context, window vs tab type hint behavior)

**Technical Debt:**

- None critical — code review fixes applied to all 4 warnings found in Phase 11
