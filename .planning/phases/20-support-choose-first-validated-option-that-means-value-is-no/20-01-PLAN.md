<objective>
Add a `first_valid` sentinel path to the existing `select_by_index` action. When an
element is `type: select`, `action: select_by_index`, and `value` is the
case-insensitive string `first_valid`, select the first `<option>` whose `value`
attribute is non-empty (whitespace-only and `None` count as empty). If no option
qualifies, raise `ElementActionError`. Numeric `select_by_index` behavior must remain
byte-for-byte identical.

Purpose: Lets workflow authors skip a leading placeholder option (e.g. `value=""`
"Please select…") without knowing its index position — purely additive, no schema or
enum changes.

Output: One new unit test file (`tests/unit/test_base_page_select_first_valid.py`) and
a confined change to `src/ui/base_page.py` (sentinel branch + private helper).
</objective>

From src/ui/base_page.py (lines 237-261, the method being modified):
```python
def select_dropdown(self, locator: LocatorDefinition, by: str, value: str, name: str = "") -> None:
    el = self.wait_for_visible(locator)
    sel = Select(el)
    if by == "text":
        sel.select_by_visible_text(value)
    elif by == "value":
        sel.select_by_value(value)
    elif by == "index":
        sel.select_by_index(int(value))      # <-- sentinel branch inserts HERE, before int()
    else:
        raise ElementActionError(f"Unknown select_by '{by}'", element_name=name)
```
