when multiple `<input type="checkbox">` share the same `name` attribute. When
`locator.by == "name"` and `element.value` is non-empty, the framework auto-builds a
targeted CSS selector and interacts with that exact checkbox. Mirrors `select_radio` pattern.

Purpose: Workflow JSON authors can disambiguate grouped checkboxes using the same
name+value pattern already established for radio buttons — no new action types required.

```python
def select_radio(
    self, locator: LocatorDefinition, name: str = "", value: str = ""
) -> None:
    """Select a radio button.

    When ``value`` is set and ``locator.by == "name"``, locates the radio
    element via ``input[type="radio"][name="..."][value="..."]`` CSS selector.
    Otherwise uses ``locator`` directly.
    """
    if value and locator.by == "name":
        css = f'input[type="radio"][name="{locator.value}"][value="{value}"]'
        target: LocatorDefinition = LocatorDefinition(by="css_selector", value=css)
    else:
        target = locator
    el = self.wait_for_visible(target)
    if not el.is_selected():
        el.click()
```
