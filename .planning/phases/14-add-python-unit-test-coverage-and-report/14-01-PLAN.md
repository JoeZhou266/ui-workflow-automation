<objective>
Wire pytest-cov into the project so that every `pytest` run automatically measures line coverage
across all of `src/`, prints a per-file summary with uncovered line numbers to the terminal, and
writes a browsable HTML report to `reports/coverage/`. No minimum threshold is enforced — this
phase is about visibility only.

Purpose: Give developers immediate feedback on which source lines are exercised by the test suite,
without any build-blocking. The HTML report provides drill-down to individual lines.

Output:
- `requirements.txt` — `pytest-cov>=4.0.0` appended
- `pytest.ini` — `addopts` extended with three coverage flags
- `.coveragerc` — new file configuring source scope, omit rules, and HTML output directory
- `.gitignore` — `reports/coverage/` added to the reports exclusion block
</objective>
